# 🚀 KPS KOS Automation Scripts

Este repositório contém alguns dos meus scripts usando o **Kerbal OS** que é um mod de piloto automatico desenvolvido para o jogo **Kerbal Space Program**

A Ideia é guardar diversos tipos de scripts para a versão stock do game (versão padrão) quanto para o mod RO (Realism Overhaul) que transforma o jogo para ser algo mais proximo a vida real

# 📁 Estrurura do repositório

```text
ksp-kos-scripts/
├── Stock/                  #Pasta com scripts para a versão padrão do jogo (Stock)
|   ├── expendeble.ks       #Lançamentos com o descarte do booster
└── RO/                     #Pasta com scripts para o mod Realism Overhaul
    ├── expendeble.ks       #Lançamentos com o descarte do booster
```

| Automação / Módulo | Modo | Descrição | Status |
